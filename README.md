# OpenStem Application

Trialing application that supports the OpenSTEM Hubs

## Requirements

[ ] - Node.js ^18.0

[ ] - pmpm package manager

[ ] - AWS CLI

[ ] - AWS Amplify

## How to use it?

### Install dependencies

```bsh
pnpm install
```

### Run APP in develop

```bsh
pnpm dev
```

### Pre Commit to Github and Deploy to Amplify

```bsh
pnpm precommit
```

## Build locally

```bsh
pnpm build
```

### CI/CD setup in github on main so just precommit and make a feature branch on merge changes will deploy

### Amplify CLI Commands found online in documentation [AmplifyDocs](https://docs.amplify.aws)
