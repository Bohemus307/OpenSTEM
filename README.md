# OpenStem Application

Trialing application that supports the OpenSTEM Hubs

## Requirements

[ ] - Node.js ^18.0

[ ] - pmpm package manager

[ ] - AWS CLI

## How to use it?

### Install dependencies

```bsh
pnpm install
```

### Run APP in develop

```bsh
pnpm dev
```

### Pre Commit to Github

```bsh
pnpm precommit
```
